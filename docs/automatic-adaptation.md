# 自动适配与开源变更 · 0.8.0-rc.14

日期：2026-10-30

## 问题与行为

旧启动器把 Codex 版本号及三个 renderer 模块的文件名、散列、导出别名写死
Codex 从 26.1023.6621.0 更新至 26.1027.3384.0 后，启动器整体拒绝加载，任务与草稿接口也被判定失配

现在不再按版本号挡住底栏；分别检查使用量入口、完成事件和草稿发送
通过当前客户端的语法树、导出关系及语义标记识别接口，使用固定版 Acorn 解析，不执行安装包源码
文件名、导出别名、局部变量名及字符串引号样式变化可独立识别
缺失或歧义接口仅使相关能力不可用；刷新提醒和基础布局不依赖草稿/完成事件接口
发送仍调用原生提交处理器，保留草稿、账号、当前轮次及提交状态校验
新版原生导航通过 navigateToLocalConversation 调用；旧版精确散列表保留已验证的原生 helper

## 适配表

启动时请求固定公开 GitHub 地址，检查间隔至少 12 小时，网络超时 3.5 秒
随包 Ed25519 公钥验证签名，校验表结构和版本，拒绝旧表替换新表
每个条目必须与本机 renderer 模块的 SHA-256 全部一致才能应用
只接受声明式导出映射，不接受脚本或命令，不下载执行远端 JavaScript
无匹配表时使用本机语法识别，断网保留随包表和已验证缓存
表更新在下次启动生效，不主动重载聊天或开启任何功能开关
维护者仍须适配结构性变更，不能保证所有未来版本无需维护
维护签名私钥保存于仓库外，绝不进入 Git 或安装包，流程见 updates/README.md

## 开源

按项目所有者选择，自有程序、原创 SVG 图标与说明采用 GPL-3.0-only
保留 Codex Bottom Bar contributors 和由龙见象的版权声明，根 LICENSE 使用完整 GPLv3 原文
Node、Acorn 及录音资源分别保留原有权利；GPL 不替代 OpenAI 的服务或软件条款
README、三种语言的安装说明、项目元数据及源码打包方式已改为公开项目语境
历史 sales 内容仅作旧版准备记录，不再作为当前许可或销售状态

## 验证范围

- 50 项核心检查包含语法识别、单能力缺失、歧义、签名校验、篡改、回退和离线缓存
- UI 79 项、语言 33 项、显示 25 项、音量 20 项检查
- 原生适配器模拟检查覆盖三语入口、直接使用量页面、独立能力、两种导航方式、草稿去重、失败保留、账号切换及取消
- 定时发送重排检查覆盖重置卡更换时间、旧目标不发送、等待缺失时间、自然刷新执行一次
- 隔离控制器、提醒后台、启动参数、安装卸载、同路径升级、PID 复用及设置持久化检查
- 当前 Codex 26.1027.3384.0 只读识别完成事件与草稿接口均通过，原生使用量绑定也通过
- 公开检查范围：Git 当前跟踪/非忽略文件、现存历史文本 blob、仓库预览图片，结果见 open-source-audit.json

新增多层 vendor/acorn 目录时，安装回归发现卸载后残留空父目录，已改为按受管理文件的全部父路径由深至浅清理空目录，不递归删除用户文件

GitHub Windows 检查还发现测试注入脚本在默认 Continue 错误策略下可能把子脚本异常返回为退出码 0
测试包装器现明确使用 Stop，保留全部逐字节回滚断言，并在异常退出码不符时附带有界错误片段；没有放宽安装回滚要求

未重启或重载当前 Codex，未发送真实聊天草稿，未播放真实音乐
真实冷启动、原生系统通知返回、真实多聊天提交及真实任务完成属于另外的客户端人工验收范围
