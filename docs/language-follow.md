# 0.8.0-rc.3 语言跟随设计与验收

界面语言直接跟随 Codex 的 document.documentElement.lang，支持 zh-CN / en / ja 及相应区域变体
不读取独立的手动语言配置，不提供选择器，旧 config.language 值不再覆盖 Codex
Codex 暂时未提供 lang 时使用客户端环境语言，不支持的语言退回英文

监听根元素 lang 属性，更新已有的额度文字、分钟倒计时、三个按钮的提示、辅助阅读标签和音量提示
不重建按钮，不重新连接草稿适配器，不改变开关、日期显示选择、计划时间或发送轮次
通过受控的 ui-language 消息将中文/英文/日语同步至独立提醒服务
托盘在原 UI 线程更新，切换语言不重启播放进程，不重新播放音乐或增加通知
Codex 关闭后从独立状态目录 codex-language.json 保留最后一次语言，仅保存语言代码
设置窗口没有语言选择器，仍可设置时区和 WAV，并跟随已识别的 Codex 语言更新文字

中文 auto 时间保留北京时间，英文/日文 auto 使用本机时区，手动时区选择不受语言切换影响

新增检查覆盖区域语言、完整日语词条、日语倒计时、实时三语切换和可见提示原位更新
独立 CDP 桥接验证语言传递到真实 Windows 托盘，保留同一后台 PID、提醒计划与待发送轮次
日语底栏和无选择器设置窗口的模拟图已查看，无文字截断，沿用系统字体
测试只使用模拟聊天和静音音频，不提交真实草稿、不调整系统音量
完整买家冷启动和真实多聊天提交仍属于此前未完成的独立验收范围
