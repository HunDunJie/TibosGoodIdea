# 第二轮复查修复

候选版：0.8.0-rc.7，日期：2026-10-30

本轮检查了启动/恢复/卸载、提醒后台、账户切换及原生功能连接，确认并修复以下问题。

1. 日语头像入口未被识别。原生任务/草稿桥接和直接打开使用量页面均只匹配中英文头像标签，日语下无法取得客户端状态。根据当前受支持客户端包中的 `codex.profileDropdown.profile` 和 `codex.profileDropdown.usage` 翻译，补齐日语头像及使用状况入口。测试使用真正的 UTF-8 日语标签，不以浏览器界面翻译作为替代。
2. 切换账户时可能先触发旧账户到点提醒。有效的新账户用量样本现在先取消旧账户计划，再处理到期事件，避免播放旧账户音乐或弹出旧账户通知。同账户在刷新后到达的样本仍保留原定的刷新后一分钟提醒。
3. 提醒后台与语言缓存没有采用控制器已有的短暂读锁重试。抽出共用的状态写入函数，先写临时文件再替换，遇到 EBUSY、EPERM、EACCES 有限重试。持续错误仍会报告，不将失败写入当成成功。

## 验证

- 核心单元测试 30 项通过，新增到点切换账户场景，确认没有旧账户播放/通知调用
- 原生适配测试覆盖中文、英文、日语头像；三个语言均成功取得账户状态并直接打开使用量页面，原有草稿去重、账户切换及单轮取消测试通过
- 语言界面测试 33 项通过，保留当前按钮、悬浮提示、功能开关和时间显示选择
- 独立提醒后台在 features.json 和 codex-language.json 分别被 Windows 文件句柄锁定 800 毫秒时，写入成功且进程没有退出；提醒计划和待发送轮次保持
- 安装检查 102 项通过；多副本启动、崩溃后恢复及原有控制器集成通过
- Node 语法、PowerShell 解析、脚本编码/换行及 Git 差异格式检查通过

所有集成检查均使用隔离状态、临时安装目录或无界面模拟页面，没有连接真实 Codex、发送真实草稿、播放实际音乐或弹出提醒通知。当前用户配置、现有控制器和提醒服务未变更。完整真实客户端人工验收仍待用户试用，未公开发布或提交 GitHub。
