# 定时关闭设计与审查

状态：已完成三轮设计审查与三轮实现审查，发布仍须通过统一完整测试和 GitHub CI

## 已确认规则

- 图标顺序：定时关闭、定时发送、完成提醒、刷新提醒，沿用现有样式及中英日跟随语言
- 手动开启、本次会话有效；按钮或托盘关闭时，先作废计划标识，再删除本工具的 Windows 任务计划
- 定时发送 armed/running 时完全暂停任务和网络检查，并撤销已有关机计划；发送进入任何终态后立即检查
- 开启立即检查，此后每 180 秒检查；倒计时仍按 180 秒检查，到期额外做一次最终核验
- 全部空闲则安排 300 秒后关机；检查发现新任务或信息无法确认，取消当前计划，继续等待；下一次空闲重新计满 300 秒
- 网络异常单独分类：连续两次检查间隔至少 180 秒、两个独立 HTTPS 探测均失败，且任务快照确认没有本地工具/审批/队列仍执行，视为无法继续，可以倒计时；期间恢复后仍有任务即取消
- 定时发送的暂停规则高于网络异常；失败、额度耗尽等已终止任务不永久阻止关机

## 实现边界

任务快照由现有 CDP 控制器只读取得，不切换聊天，不读/上传正文：枚举主机、原生 getWorkInProgress、完整分页 thread/list 与本地执行保护。未初始化的 durable 内置主机可忽略；已连接主机断开、未知状态、分页不完整、接口改变均不能冒充空闲。支持能力由语法结构发现，与完成提醒、定时发送分开降级

独立后台保存状态并串行处理所有开关/快照/执行。每次检查有唯一请求 ID，过期报告不能创建或执行计划。控制器健康心跳只检查连接，不额外检查任务。超过健康期限、服务重启、Codex 退出、恢复原界面均取消旧计划。睡眠/时钟跳变后重新检查、重新计时

Windows 计划任务只调用关机守卫，守卫只请求当前后台做最终检查；后台不存在/计划已作废时不会关机。最终快照必须新鲜，后台再次核对定时发送、计划 ID 和开关，才运行 System32/shutdown.exe /s /f /t 0。避免应用保存对话框阻止关机，同时明确告知未保存内容会丢失。记录系统退出码；失败显示错误并关闭本次自动关机，避免无界重试

计划名称由当前用户及状态目录确定，任务描述核对所有权，只取消自己的任务。取消先持久化作废状态，删除任务失败也不能让守卫继续执行。后台队列保证取消/执行的明确先后；Windows 已开始最终关机后无法承诺撤销

## 设计审查 1：规则和交互

核对 180 秒检查与 300 秒倒计时、定时发送优先级、按钮/托盘双取消、无草稿/发送失败终态、额度不限账户、三语言。取消不重新开启；后台重启和电脑重启默认关闭。结论：规则一致

## 设计审查 2：竞态及故障

核对过期快照、同一请求多窗口回复、注册任务后取消、最终核验中取消、新发送开始、睡眠、断连、系统任务删除失败、其他程序的关机任务。采用请求/计划随机 ID、串行处理、最终核验和专属系统任务，避免直接提前交给 Windows 不可监管的长倒计时。结论：可实现，无需全局 shutdown /a

## 设计审查 3：完整性与可验证性

网络连接异常不能简单等同空闲；双探测、间隔确认、本地工作保护与主机完整性独立判断。通过 Codex 的 Chromium 网络会话探测，遵循客户端代理设置，不使用 Node 独立直连的结果；不携带凭据、不读取响应正文，接口不支持或探测被拦截时记为未知。任务状态未知与网络确认异常分开；前者继续等待。测试注入调度器、网络、时钟与系统命令，禁止自动化测试真实关机。覆盖安装卸载、服务退出和更新交接，自动更新应在定时关闭开启时推迟。结论：按本文实现；发布类型为 feature

## 实施后三轮审查

1. 控制与所有权：发现并修复后台在取得单实例锁前清理旧关机计划的风险；取得锁后才处理旧计划，卸载核对状态所属安装。取消先持久化作废，再删除系统任务；任务守卫从不直接执行关机
2. 竞态与异常：增加取消意图序号，每次检查绑定其签发时的序号，最终报告在队列等待或关机前持久化期间收到关闭或新定时发送请求时均撤销执行；按钮、托盘、服务重启及退出信号都记录取消意图。修复任务创建失败后清理也失败的错误路径，以及关机调用失败后的无界重试风险。覆盖新任务、断连、超时、时钟跳变、网络恢复、本地工具保护和错误的分页游标
3. 完整性与界面：检查了三语言、Pro 无五小时限制账户、四图标顺序、悬浮提示保留、更新交接和源码/买家包清单。恢复已审阅截图，新增图标的本地视觉检查记录为单行、低亮度，与已有图标间距一致。共享语法索引，避免启动适配时重复解析大模块。增加持久化清理标识，删除计划失败后可再次清理；从未安排计划的安装不因任务计划服务不可用而无法卸载

已取得的验证证据：快速流程 57 步通过（103 个单元测试）、UI 86 项及语言 33 项检查通过；Windows 真实计划注册及重复取消通过，没有调用真正关机。当前实机只读任务快照为 known=true/busy=true/localSafe=false，客户端网络探测 available=true，未启用关机，也未替换当前全局适配器。新增取消持久化竞态、已排队取消意图、代理会话断网和重复后台进程保护测试纳入发布前完整流程

范围限制：连通性探测证明的是持续不可达或站点服务错误，不能将认证失败、额度不足或任意单个请求报错都等同于断网。已终止任务不算运行中；仍有审批、队列、本地工具或无法读取完整任务状态时继续等待。持续网络故障的确认间隔为 180 秒，此后另有 300 秒倒计时
