# 快速开始

1. 下载 Windows-x64 ZIP，完整解压到你希望长期保存的位置
2. 首次使用前完成任务并自行退出 Codex
3. 双击唯一的启动入口 **Start.cmd**

无需安装、无需管理员权限，不创建快捷方式，不把程序复制到 AppData。内含校验过的 Node.js。以后也从 Start.cmd 加载底栏；原生 Codex 入口保持原样。可以自己为 Start.cmd 创建 Windows 快捷方式

## 自动更新

每次启动都会检查 Codex 适配和 TiBo 新版本，包括修复与功能更新。Codex 指纹变化时检查对应适配；Codex 没变时也检查 TiBo 自身更新，只下载确认兼容当前客户端的版本。不需要检查更新工具或手动点更新

客户端已退出且服务不忙时，本次启动自动切换；运行中的 Codex 不热切换，新版本暂存到下次安全启动。正在发送、响铃、两分钟内有提醒或定时关闭监控开启时也推迟切换。下载失败继续使用当前可用版本

旧版安装用户请下载本版并解压到自己选定的目录，退出 Codex 后运行 Start.cmd。验证旧服务归属后迁移设置与提醒状态，不迁移关机倒计时。旧安装文件暂保留，不再创建安装副本；旧快捷方式仍指向旧目录，请改用新入口

## 文件和管理

- config.local.json：个人设置，首次保存时建立
- data：日志、语言、提醒状态及启动检查结果
- versions：自动下载并校验的更新，仍在当前目录内
- install-info.json：便携目录归属记录，名称用于兼容旧更新器，不代表复制安装
- 托盘图标：左键停铃；右键打开 **TiBo 设置**、**打开 TiBo 文件夹**、停止提醒或取消关机计划
- **退出 TiBo**：恢复界面、停止提醒并取消关机计划，不强制关闭 Codex
- 删除或移动前先在托盘选择 **退出 TiBo**，再处理整个文件夹；外部自选音乐不受影响

设置支持时区及 WAV，留空使用随包音乐。语言跟随 Codex（中文、英文、日语），设置下次启动生效，无需额外 CMD

## 底栏功能

从左到右为定时关闭、定时发送、完成提醒、刷新提醒，悬停查看状态

定时关闭每 3 分钟检查所有聊天，确认无任务后安排 5 分钟关机；定时发送开启时暂停，发现新任务撤销计划。按钮及托盘均可取消。持续断网也需确认无本地工具执行。关机会强制关闭应用，未保存内容会丢失

定时发送每次手动开启，只执行下一次刷新的一轮，将所有聊天已有非空草稿通过原提交入口发送。需保持 Codex 运行。修改过、失败或不支持的草稿会保留，不自动重试

完成提醒只播放音乐；刷新提醒在五小时刷新后一分钟通知并播放音乐，退出 Codex 后仍可响铃。最多循环 30 分钟，操作 Codex（包括鼠标移动）会停止，也可从托盘停止。电脑需保持开机，关机、休眠或注销期间无法播放
