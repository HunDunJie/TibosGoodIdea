# Default notification tones

`completion.wav` and `refresh.wav` are original synthesized sine-wave sequences made for this project with `make-tones.py`. They do not contain the seller's game music or third-party recordings. This release includes them under the commercial self-use license in LICENSE.en.md.

Both are 5-second mono PCM WAV files at 22050 Hz / 16 bit. The reminder service loops them for at most 30 minutes, subject to the existing stop rules. Choose another WAV in Settings if desired. No tone plays during installation.

内置的两个音效由本项目的脚本合成，本版本适用商业自用许可草案，不包含卖家的私人游戏音乐。可以在设置中换成自己有权使用的 WAV 文件，安装时不会播放音效。
